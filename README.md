# Car Rental Application

A modern, responsive car rental web application built with HTML and CSS.

## 📋 Overview

The Car Rental Application provides users with an intuitive platform to search, browse, and rent vehicles. It features a clean, user-friendly interface with mobile-responsive design, showcasing available cars with detailed information including pricing, specifications, and availability.

## 🌟 Features

- **Search & Filter**: Find cars by location, date, and time
- **Car Categories**: Browse popular and recommended vehicles
- **Detailed Listings**: View car specifications (fuel capacity, transmission, passenger capacity)
- **Responsive Design**: Optimized for both desktop and mobile devices
- **Interactive UI**: Like/favorite cars, view details, and rental options

## 🎨 Pages

- **index.html** - Main landing page with car listings and search functionality
- **detail.html** - Detailed car information page
- **catergory.html** - Category-based car browsing
- **admin.html** - Admin dashboard
- **payment.html** - Payment processing page

## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process or dependencies required!

### Local Development

Simply open any HTML file in your browser to view the application:

```bash
# Open main page
open index.html
# or
xdg-open index.html  # Linux
```

## 🎯 Usage

### Searching for Cars

1. Use the search bar to filter available vehicles
2. Select pick-up and drop-off locations from the dropdown menus
3. Choose your preferred date and time
4. Browse available cars in the "Popular Car" and "Recommendation Car" sections

### Viewing Car Details

- Click on any car card to view detailed information
- Check specifications: fuel capacity, transmission type, and seating capacity
- View pricing information with daily rates

### Mobile Experience

The application features a mobile-optimized header with:
- Collapsible navigation
- Streamlined search interface
- Touch-friendly controls
